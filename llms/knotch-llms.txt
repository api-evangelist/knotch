# Knotch

> Knotch is a New York-based content intelligence company. Its Knotch One platform measures and
> optimizes owned-content performance for enterprise marketing teams, and its newer product, Ace,
> is positioned as "AI experience infrastructure for the conversational web" — ingesting a brand's
> existing web properties, atomizing them into modular content units tagged by topic, audience,
> funnel stage and intent, then composing adaptive page experiences for human visitors while
> emitting structured, citable content for AI agents and answer engines.

## Status

Knotch publishes a real developer surface, on two documentation hosts that are not linked from the
marketing site. Corrected 2026-08-13: an earlier version of this file said Knotch had no public
API. That was wrong.

- A server-side REST API, the **Knotch Events API v1.1**, backed by a live OpenAPI 3.1.0 served at
  https://events.knotch.it/openapi.json, with interactive docs at /docs and /redoc.
- Browser-side APIs — the Measurement Unit API, the Event Pixel and the Verification Pixel —
  documented at docs.knotch.it.

Access is sales-led. Documentation is public and anonymous, but credentials are not self-service:
Events API keys come from a Knotch Client Success Manager, Event Pixel Account IDs from the Client
Success team, and Verification Pixel kvpids from blueprint@knotch.com. There is no pricing page,
no self-service signup, no status page, no changelog, no SDK on any package registry, no CLI, no
public GitHub organization, no MCP server, no A2A agent card, and no /.well-known/ document on any
host.

This file is generated from the API Evangelist catalog entry and the artifacts in this repo, not
harvested from a Knotch-published llms.txt — Knotch does not publish one.

## APIs

- [Knotch Events API](https://help.knotch.com/en/articles/159-events-api-v11-technical-overview):
  Server-side conversion event ingestion. `POST https://events.knotch.it/conversion_events/{account_id}`
  (and a Segment webhook variant at `/conversion_events/segment/{account_id}`). Bearer auth,
  batches of 1-100 events, `simulate=true` validates without storing. Deduplicated on a
  client-supplied `event_id`; duplicates return 409 Conflict.
- [Knotch Measurement Unit API](https://docs.knotch.it/unit_api/): Browser JavaScript API —
  `Knotch.addUnit()`, `removeUnit()`, `setFocus()`, `enableUnit()`, `disableUnit()`,
  `setOptout()` — plus the `knotch-ignore` HTML attribute.
- [Knotch Event Pixel](https://docs.knotch.it/event_pixel/): HTTP beacon at
  `https://t.knotch.it/receive/beacon.gif?account_id=&event=&page_url=&ts=` for arbitrary
  conversion, journey and signal events.
- [Knotch Verification Pixel](https://docs.knotch.it/verification_pixel/): Publisher traffic
  verification tag (Knotch Blueprint), a script with a `data-kvpid` attribute.
